# The protocol trace vocabulary (design record 012, increment 3).
#
# `event <Name>` lines are the events the engine may emit
# (protocol_trace::Event("<Name>") in the source tree); every one must be
# consumed by formal/trace/TraceExactlyOnce.tla (Is("<Name>")).
# `unobserved <Action>` lines are specification actions the engine cannot
# observe and so never emits; the trace module lets TLC take them as hidden
# steps. Every other action in ExactlyOnce.tla's Next must be reached by
# some event. scripts/check-protocol-trace-events.py holds the three in
# agreement.
#
